Shared behavior

  • Running durations update once per second.
  • Completed and failed durations remain frozen.
  • The aggregate value mirrors the latest tool call.
  • Sub-second calls use milliseconds; longer calls use seconds.

Accessibility

  • Duration is never the only state signal.
  • Screen-reader text retains running, completed, and failed.
  • Tabular numerals prevent width jitter while ticking.
  • Reduced-motion settings stop decorative activity effects.
